# Narrative Book

The narrative book is a readable historical narrative generated only from approved claims.

It is not historical fiction.

Target:
- immersive but restrained prose;
- no unsupported dialogue or inner thought;
- no concealed harmonization;
- chapter-level source audit;
- source notes/endnotes that allow readers to trace major claims.

A chapter is not final until its historical assertions map to Claim IDs.
