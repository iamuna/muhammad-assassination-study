# Muhammad Assassination Study

A source-critical research project on reported attempts against the life of Prophet Muhammad ﷺ.

## Project principle

This repository does not begin with a predetermined number of assassination attempts or a predetermined historical conclusion.

The workflow is:

**source evidence → atomic claims → transmission analysis → competing evidence → grading → narrative permission → source book → narrative book**

The project distinguishes:
- what a source explicitly states;
- what can reasonably be inferred;
- what later tradition adds;
- what is disputed;
- what is unknown.

No unsupported detail is promoted into historical fact for dramatic effect.

## Repository map

- `methodology/` — grading, source hierarchy, claim schema, narrative rules.
- `source-registry/` — permanent IDs for sources and editions.
- `claims/` — atomic historical claims and contradiction tracking.
- `incidents/` — one research dossier per alleged incident.
- `source-book/` — evidence-facing reference volume.
- `narrative-book/` — readable historical narrative built only from permitted claims.
- `bibliography/` — bibliography and citation infrastructure.
- `research-log/` — methodological decisions and regradings.
- `source-wishlist.md` — prioritized acquisition list.

## Evidence policy

Repeated publication does not equal independent corroboration. Later works that derive from one earlier report are treated as one evidentiary stream unless independence can be demonstrated.

Every major claim should eventually be traceable to:
1. source ID and edition ID;
2. exact passage and location;
3. original Arabic where available;
4. translation;
5. transmission/isnād information where applicable;
6. parallel reports and dependencies;
7. contradictions and variants;
8. claim-level score;
9. confidence class;
10. narrative permission.
