# Source Discovery and Acquisition Policy

## Purpose

Use the internet aggressively for source discovery, but never confuse a catalog/search label with a verified edition.

## Preferred discovery channels

- Internet Archive
- Noor Library
- university digital collections
- national-library catalogs
- WorldCat / library metadata
- publisher catalogs
- reputable hadith/heritage databases for locating reports

## Verification rule

A book is not marked `EDITION-VERIFIED` merely because a website title appears to match.

Before an edition is locked, verify as many of the following as possible from the actual scan:

1. author/work title;
2. editor / muḥaqqiq;
3. publisher;
4. edition number;
5. publication year;
6. volume number;
7. pagination;
8. hadith numbering / internal locator;
9. title page or copyright page;
10. file fingerprint when a local copy is supplied.

## Metadata-conflict rule

If a discovery site title and the scan/description disagree, the scan wins.

Example encountered 2026-09-18:
A Noor listing labeled Sunan Abī Dāwūd as a Muʾassasat al-Risālah publication, while its descriptive text referred to the Muḥammad ʿAwwāmah edition. Such a source may still be useful for discovery, but cannot be locked as the Arnaʾūṭ/Qarah Ballī edition without inspecting the actual title page.

## Internet Archive / Noor workflow

1. Search exact author + title + editor + publisher + year.
2. Prefer the original Internet Archive item when Noor identifies Archive.org as its source.
3. Inspect title/copyright pages.
4. Record exact edition ID in the registry.
5. Use the scan directly for research when accessible.
6. Ask the author to upload only when:
   - the scan cannot be accessed reliably;
   - we need a permanent local verified copy;
   - page images are required for a disputed reading;
   - or the source is available only through the author's lawful access.

## Publication rule

No final citation may rely solely on a Noor/Archive search-result title when an exact edition scan can be checked.
