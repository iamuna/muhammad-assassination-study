# Research Worklog

This file records the **process** of the project in chronological order.

It is distinct from:
- `research-log/decisions.md` — why conclusions or grades changed;
- `source-registry/` — what editions/copies were found and verified;
- `claims/claims.csv` — atomic historical propositions and grades;
- `incidents/*` — incident-level evidence dossiers.

The purpose of this log is to preserve **what was done, in what order, and why**.

## Ongoing procedure for every incident

For each incident:

1. Locate earliest and strongest surviving evidence.
2. Verify exact edition if possible.
3. Record Arabic text for historically significant wording.
4. Map transmission families.
5. Collapse dependent repetitions.
6. Identify contradictions and variants.
7. Split the narrative into atomic claims.
8. Grade each claim separately.
9. Run adversarial challenge.
10. Reclassify if necessary.
11. Assign Narrative Permission.
12. Record the decision in `research-log/decisions.md`.
13. Only then allow the claim into the narrative manuscript.
14. After drafting, audit every narrative paragraph back to Claim IDs.

## Rule

If a correction is discovered later, the project does **not** silently overwrite the old conclusion.

The worklog records the step.
The decision log records why it changed.
Git records the exact file history.
